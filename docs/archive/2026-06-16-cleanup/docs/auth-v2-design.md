# ByteForge 认证页面 V2 设计说明

## 🎨 设计理念

全新的认证页面采用**赛博朋克**和**未来科技**风格，与原版简洁设计形成鲜明对比。

## ✨ 核心特性

### 1. 视觉效果
- **粒子动画背景** - Canvas 实现的动态粒子系统，粒子间自动连线，鼠标交互响应
- **霓虹灯光效果** - 青色、紫色、粉色的霓虹配色方案
- **扫描线动画** - 模拟 CRT 显示器的扫描效果
- **玻璃态效果** - 半透明毛玻璃材质，背景模糊
- **全息 Logo** - 三层脉动光环配合发光核心

### 2. 交互设计
- **悬停反馈** - 输入框、按钮、链接都有霓虹发光效果
- **流光边框** - 面板顶部持续流动的渐变线条
- **密码可见性切换** - 点击眼睛图标切换密码显示
- **平滑过渡** - 登录/注册表单切换带淡入动画
- **加载状态** - 提交时按钮显示旋转图标

### 3. 装饰元素
- **品牌展示区** - 左侧独立面板展示 Logo 和品牌信息
- **实时统计** - 显示用户数、会话数、系统运行时间
- **状态指示器** - 右上角绿色呼吸灯显示系统就绪
- **科技感字体** - Orbitron（标题）+ Rajdhani（正文）

## 📱 响应式设计

- **桌面端 (> 1200px)** - 显示完整双栏布局
- **平板端 (600px - 1200px)** - 隐藏装饰面板，保留表单
- **移动端 (< 600px)** - 紧凑布局，优化触摸交互

## 🔧 技术实现

### 粒子系统
- 80 个粒子随机运动
- 粒子间距 < 150px 时自动连线
- 鼠标 200px 范围内粒子会被推开
- 60 FPS 流畅动画

### 性能优化
- Canvas 使用 requestAnimationFrame
- 响应式设计隐藏非必要元素
- CSS 动画使用 transform（GPU 加速）
- 字体预加载避免闪烁

## 🎬 动画效果

1. **页面加载** - 表单淡入 + 向上滑动
2. **统计数字** - 从 0 滚动到目标值
3. **Logo 光环** - 三层错时脉动
4. **扫描线** - 持续向下移动
5. **按钮悬停** - 流光扫过效果
6. **输入聚焦** - 霓虹发光边框
7. **表单切换** - 淡入淡出过渡
