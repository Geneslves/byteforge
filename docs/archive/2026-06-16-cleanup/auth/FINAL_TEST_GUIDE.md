## 🔍 如果注册还是失败

可能需要查看服务器窗口的错误日志。常见问题：

1. **JWT_SECRET 未加载** → 重启服务器
2. **数据库表缺失** → 已手动创建，应该没问题
3. **其他错误** → 查看 PowerShell 窗口的红色错误信息
